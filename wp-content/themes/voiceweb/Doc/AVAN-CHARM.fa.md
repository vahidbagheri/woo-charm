# هویت و صفحات آوان چرم

وضعیت این نصب در ۱۶ اکتبر ۲۰۲۶: نام فروشگاه **آوان چرم** و شمارهٔ تأییدشدهٔ تماس **۰۹۱۰۱۷۱۹۶۸۷** است. تولید صفر تا صد در مجموعه و استفاده از چرم طبیعی گاوی و بزی متناسب با نیاز محصول، طبق توضیح مالک برند وارد محتوا شده‌اند. سایر اطلاعات محصول مانند قیمت، موجودی، ابعاد و تصاویر باید با کالای قابل‌فروش تطبیق داده شوند.

## مسیرهای اصلی خرید

| نوع صفحه | مسیر |
|---|---|
| صفحهٔ اصلی | `/` |
| فروشگاه | `/shop/` |
| کیف مردانه | `/product-category/leather-men-bags/` |
| کیف زنانه | `/product-category/leather-women-bags/` |
| کیف پول مردانه | `/product-category/leather-men-wallets/` |
| کیف پول زنانه | `/product-category/leather-women-wallets/` |
| جاکارتی | `/product-category/leather-cardholders/` |
| اکسسوری چرمی | `/product-category/leather-accessories/` |
| فهرست راهنماهای هدیه | `/gifts/` |
| دربارهٔ ما | `/about/` |
| تماس | `/contact/` |
| مجلهٔ آوان چرم | `/blog/` |

هر دسته، همان آرشیو بومی ووکامرس و تنها مقصد اصلی خرید آن خانوادهٔ محصول است. لینک‌های منو به خود دسته یا برگه متصل‌اند و با تغییر permalink از URL سفارشی ثابت استفاده نمی‌کنند. دسته‌ها به راهنماهای هدیه و دسته‌های مرتبط لینک دارند؛ لندینگ‌های هدیه نیز به محصولات و دسته‌ها متصل‌اند.

## ویرایش محتوا

- **دربارهٔ ما:** از برگهٔ «دربارهٔ آوان چرم»، متن اصلی، معرفی، تصویر، مراحل تولید، توضیح چرم‌ها و پرسش‌ها را تغییر دهید.
- **تماس:** از برگهٔ «تماس با آوان چرم»، شماره و اطلاعات تماس را ویرایش کنید. ایمیل، آدرس، ساعت پاسخ‌گویی، اینستاگرام و واتساپ فقط پس از تکمیل فیلد خودشان دیده می‌شوند. شمارهٔ تلفن به‌تنهایی واتساپ فرض نمی‌شود. این صفحه مسیر تماس واقعی دارد و فرم نمایشی ندارد.
- **دسته‌ها:** از «محصولات ← دسته‌بندی‌ها» دستهٔ موردنظر را ویرایش کنید. بخش «راهنمای خرید و سئوی دسته» شامل مقدمه، راهنما، نکته‌ها، FAQ، دسته‌ها و هدیه‌های مرتبط، عنوان و توضیح سئو است. محصولات با دسته‌بندی معمولی ووکامرس مدیریت می‌شوند.
- **مناسبت‌ها:** متن و محصولات هر ۲۰ برگه مستقل‌اند؛ [راهنمای مدیریت مناسبت‌ها](GIFT-LANDINGS.fa.md) را ببینید.
- **صفحهٔ اصلی:** عنوان و توضیح سئو، متن معرفی برند، داستان ساخت و ارزش‌ها در فیلدهای ACF صفحهٔ اصلی هستند.
- **مجله:** نوشته‌های دستهٔ «مجلهٔ چرم» (`leather-journal`) و زیردسته‌هایش در `/blog/` نمایش داده می‌شوند. مقالهٔ تازه را در همین دسته قرار دهید. پیشنهادهای کنار مقاله‌های چرمی نیز از همین مجموعه‌اند. صفحه‌بندی از query اصلی وردپرس استفاده می‌کند و هر صفحه canonical خودش را دارد.

نشانی قبلی فهرست مجله یعنی `/category/leather-journal/` با ۳۰۱ به `/blog/` منتقل می‌شود و شمارهٔ صفحه را حفظ می‌کند. لینک‌های منو، صفحهٔ اصلی و دستهٔ همین مجله به مقصد اصلی اشاره می‌کنند. این انتقال فقط فهرست همین مجله را پوشش می‌دهد؛ نشانی مقاله‌ها عوض نشده است.

## لوگو و حرکت

لوگو در هدر دسکتاپ، موبایل و فوتر از `template-parts/brand/logo.php` می‌آید: نشان برداری اختصاصی، نام فارسی و نوشتهٔ AVAN CHARM. نشان در `assets/images/avan-charm-mark.svg` قرار دارد و به‌عنوان favicon هم استفاده می‌شود. برق آرام لوگو با CSS اجرا می‌شود و با تنظیم `prefers-reduced-motion` غیرفعال است. لوگوی آپلودشده از تنظیمات هدر/فوتر می‌تواند جایگزین لوگوی پیش‌فرض شود.

## سئو و نگهداری

عنوان و توضیح اختصاصی، canonical و دادهٔ ساختاریافته مطابق نوع صفحه تولید می‌شوند. صفحات درباره و تماس به ترتیب `AboutPage` و `ContactPage` هستند؛ دسته‌ها و مناسبت‌ها `CollectionPage` دارند. دادهٔ قیمت و موجودی محصول از ووکامرس می‌آید. خروجی FAQ برای پاسخ به مشتری است و وعدهٔ نتیجهٔ ویژهٔ گوگل نیست.

فروشگاه و دسته‌ها در حالت مرتب‌سازی یا فیلتر، canonical مجموعهٔ اصلی و noindex دارند؛ صفحه‌بندی معمولی canonical جداگانه دارد. هنگام تغییر AJAX فیلترها و صفحه‌بندی، عنوان، توضیح، canonical، robots و دادهٔ مجموعهٔ صفحه نیز از پاسخ جدید به‌روز می‌شوند.

در نبود افزونهٔ سئو، این خروجی‌ها را قالب مدیریت می‌کند. پس از فعال‌سازی افزونهٔ سئو، عنوان، توضیح و تنظیمات ایندکس را در آن افزونه بازبینی و منتقل کنید تا مالک خروجی روشن باشد. در برگه، نوشته و محصول، گزینهٔ «این محتوا در نتایج جستجو نمایش داده نشود» برای موارد آزمایشی در دسترس است و آن محتوا را از sitemap بومی وردپرس خارج می‌کند.

محصول نمونهٔ قدیمی با عنوان «تست» و متن «تستی» از فهرست عمومی محصولات پنهان و noindex شده است؛ اطلاعات و نشانی آن حفظ شده‌اند. مجلهٔ فروشگاه و پیشنهادهای مقاله‌های چرمی به محتوای چرم اختصاص دارند. مطالب قدیمی گردشگری در دیتابیس باقی مانده‌اند و برای حذف، انتقال یا تغییر مسیر آن‌ها باید جداگانه تصمیم گرفته شود.

## انتقال به سایت اصلی

تغییرات این کار هم در **فایل‌های قالب** و هم در **دیتابیس وردپرس** هستند. برای انتقال کامل، برگه‌ها، فیلدهای ACF، متای دسته‌ها، رسانه‌ها، منوها و تنظیمات سایت نیز باید منتقل شوند. کپی فایل‌های PHP به‌تنهایی داده‌های واردشده را منتقل نمی‌کند.

نسخهٔ محلی اکنون محصولات و دسته‌ها را برای بازبینی نمایش می‌دهد و `blog_public=0` دارد. پس از انتقال به دامنهٔ عمومی و تکمیل اطلاعات واقعی فروشگاه، تنظیم ایندکس، robots، sitemap، canonical، HTTPS و مالکیت Search Console را روی همان دامنه بررسی کنید. [برنامهٔ پنج‌ماههٔ سئو](SEO-ROADMAP.fa.md) زمان‌بندی و سنجه‌های رشد را توضیح می‌دهد.

## فرمان‌های محلی

```powershell
# بررسی برنامهٔ تغییر برند، بدون نوشتن داده
php -d mysqli.default_port=10113 wp-content/themes/voiceweb/tools/setup-avan-brand.php

# اجرای اولیهٔ برند؛ اجرای دوباره ویرایش‌های بعدی را بازنویسی نمی‌کند
php -d mysqli.default_port=10113 wp-content/themes/voiceweb/tools/setup-avan-brand.php --apply

# نمایش فروشگاه در دامنهٔ محلی برای بازبینی
php -d mysqli.default_port=10113 wp-content/themes/voiceweb/tools/setup-avan-brand.php --preview-local

# بررسی پاک‌سازی نمونهٔ آزمایشی و عنوان مجله
php -d mysqli.default_port=10113 wp-content/themes/voiceweb/tools/refine-avan-seo.php

# بررسی محتوا و لینک‌های واقعی
php -d mysqli.default_port=10113 wp-content/themes/voiceweb/tools/test-avan-brand.php
php wp-content/themes/voiceweb/tools/test-category-landings-http.php
php wp-content/themes/voiceweb/tools/test-gift-landings-http.php
php -d mysqli.default_port=10113 wp-content/themes/voiceweb/tools/test-catalog-seo.php
node --preserve-symlinks --preserve-symlinks-main wp-content/themes/voiceweb/tools/test-catalog-metadata.js
php -d mysqli.default_port=10113 wp-content/themes/voiceweb/tools/test-leather-magazine.php
```

پورت ۱۰۱۱۳ مربوط به همین نصب است. سازندهٔ برند و ابزار پاک‌سازی، نسخهٔ قبل را در optionهای خصوصی `voiceweb_avan_brand_backup_v1` و `voiceweb_avan_seo_cleanup_backup_v1` نگه می‌دارند. این ابزارها از اجرای نوشتن روی دامنهٔ عمومی جلوگیری می‌کنند.

## نتیجهٔ اعتبارسنجی نهایی

در ۱۶ اکتبر ۲۰۲۶، ۱۷۶ بررسی برند و صفحات، ۱۳۹ بررسی HTTP دسته‌ها، ۴۴۶ بررسی HTTP مناسبت‌ها، ۳۰ بررسی سئوی فروشگاه و ۶۹ بررسی مجله موفق بودند. ۲۹ آزمون رفتاری دسته‌ها و بررسی تغییر متادیتای AJAX نیز موفق بودند؛ داده‌های موقت آزمون پاک شدند. محصول آزمایشی در دیتابیس حفظ شده، از کاتالوگ مخفی و از query نقشهٔ سایت بومی خارج است.

این بررسی‌ها شامل محتوای واقعی پاسخ HTTP، لینک، عنوان، توضیح، H1، canonical، robots و JSON-LD هستند. مرورگر متصل برای ارزیابی تصویری دسکتاپ و موبایل در دسترس نبود.
